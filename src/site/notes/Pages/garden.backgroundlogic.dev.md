# About
I made this 'Garden' as a place to share things I make and to have a place to point people to when they ask. This website is hosted on GitHub using the GitHub Pages feature, it is a static site built using Obsidian Notes with an addon called Digital Garden. 


## How?
While obsidian notes is primarily a note taking application that functions like a wiki, digital garden uploads selected notes to a GitHub repository with a static site template, then updates GitHub Pages. Once setup the workflow is very simple, just write a note, check the box to publish, and push the notes to GitHub. After a minute the website updates with the new changes.
